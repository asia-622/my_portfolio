# 🚀 Quick Start Guide - Deploy in 5 Minutes!

## Step 1: Prepare Your Files (1 minute)

1. ✅ You have these files:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `README.md`

2. ⚠️ **IMPORTANT**: Add your CV file
   - Name it: `Asia_CV.pdf`
   - Place it in the same folder as `index.html`

## Step 2: Test Locally (1 minute)

1. Double-click `index.html` to open in your browser
2. Check that everything looks good
3. Try clicking the "Download CV" button (after adding your CV)

## Step 3: Create GitHub Account (Skip if you have one)

1. Go to https://github.com/signup
2. Create a free account
3. Verify your email

## Step 4: Create Repository (1 minute)

1. Go to https://github.com/new
2. Repository name: `yourusername.github.io` 
   (Replace `yourusername` with YOUR GitHub username)
3. Select "Public"
4. Click "Create repository"

## Step 5: Upload Files (2 minutes)

### Easy Way (No coding needed):

1. On your new repository page, click "uploading an existing file"
2. Drag all your files into the browser:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `Asia_CV.pdf`
   - `README.md`
3. Scroll down and click "Commit changes"

### Alternative - Using Git:

```bash
cd /path/to/your/portfolio/folder
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/yourusername/yourusername.github.io.git
git push -u origin main
```

## Step 6: Enable GitHub Pages (30 seconds)

1. In your repository, click "Settings" (top menu)
2. Click "Pages" (left sidebar)
3. Under "Source", select "main" branch
4. Click "Save"

## Step 7: Visit Your Live Site! (Wait 2-5 minutes)

Your website will be live at:
```
https://yourusername.github.io
```
(Replace `yourusername` with your GitHub username)

## 🎉 Done! Your Portfolio is Live!

Share your link:
- LinkedIn: Add it to your profile

- Social media: Share with your network

## 🔧 Making Updates Later

1. Edit your files locally
2. Go to your GitHub repository
3. Click on the file you want to update
4. Click the pencil icon (Edit)
5. Make changes
6. Click "Commit changes"
7. Wait 2-5 minutes - your site updates automatically!

## ❓ Need Help?

Common Issues:

**Problem**: CV download doesn't work
**Solution**: Make sure `Asia_CV.pdf` is uploaded and the name is exact

**Problem**: Site not showing up
**Solution**: 
- Wait 5-10 minutes after enabling Pages
- Check: Settings → Pages → Make sure it says "Your site is published at..."
- Try visiting in an incognito/private window

**Problem**: Changes not showing
**Solution**:
- Clear your browser cache (Ctrl+Shift+Delete)
- Wait a few minutes after making changes
- Try hard refresh (Ctrl+Shift+R or Cmd+Shift+R)
